### Featured Project

<div align="center">

  ### Bifrost: Role-Based Task Management App &nbsp;<sup>v1.1</sup>

  <img src="assets/bifrost-screenshot.png" width="80%" />

  **A full-stack task manager where admins assign and track work, and employees accept tasks and move them through New → Active → Completed / Failed.**

</div>

- Separate admin and employee dashboards. Roles are checked on every route and every server action, not just hidden in the UI
- Analytics page with area, bar and pie charts, plus search, status filters and server-side pagination
- Avatar upload, password change and optimistic delete
- Dark and light themes, and four accent colours saved to your account
- To try it, click **Try as Admin** on the login page
